## GitHub Pages

The web version can be published directly through **GitHub Pages**.

### Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the branch containing the website, such as `main`.
5. Select `/ (root)` as the folder.
6. Click **Save**.
7. GitHub Pages will provide the published website URL.

## GitHub Codespaces

This project can be opened and edited in **GitHub Codespaces**.

### Open in Codespaces

1. Open the GitHub repository.
2. Select **Code**.
3. Select the **Codespaces** tab.
4. Click **Create codespace on main**.
5. Edit the web application files in the browser-based VS Code environment.
6. Commit and push your changes to GitHub.

Changes pushed to the configured GitHub Pages branch can then be published to the live site.

## iOS App Installation Information

The original application is described as an iOS App Store package.

1. Open the **App Store**.
2. Search for **Animal Sounds**.
3. Select **Animal Sounds** from the search results.
4. Tap the download/get button.
5. Wait for the app to download and install.
6. Open **Animal Sounds** from the Home Screen.

> **Note:** The GitHub Pages web app and the historical iOS IPA are separate distribution formats. A GitHub Pages website does not itself install an IPA on iOS.
